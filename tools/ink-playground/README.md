# Ink Unterwegs

Kleiner Ink-Editor mit Live-Vorschau für Handy, iPad und Browser. Eine einzige HTML-Datei,
inkjs wird vom CDN geladen (Internet nötig). Dateien werden im Browser (localStorage) gespeichert.

- `index.html` im Browser öffnen, fertig.
- Schreiben links / Tab „Skript", durchspielen rechts / Tab „Spielen".
- Mehrere Dateien, Import von `.ink`, Kopieren in die Zwischenablage, Herunterladen.
- Kein Teil des Spiels, nur ein Werkzeug.
